Comment ajouter un document ?

Les documents sont récupérés à partir des Issues (tickets) du dépôt GitHub. Pour que cela fonctionne :

  • Créez une nouvelle "Issue" dans le dépôt Tvissouarn1/docs (qui doit être Public).
  • Le titre de l'Issue sera le titre du document.
  • Le corps de l'Issue (en Markdown) sera le contenu du document, qui s'affichera ici en pleine page.
